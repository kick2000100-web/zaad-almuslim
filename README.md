# زاد المسلم

منصة عربية RTL تعمل دون إطار عمل، وتقدم تجربة محلية قابلة للعمل دون خادم: القرآن (بيانات السور فقط حتى لا يتم اختلاق النص)، الأذكار، الحديث، المتابعة، السبحة، لوحة المحتوى المحلية، والـ PWA.

## التشغيل

افتح `index.html` عبر خادم ملفات ثابت (مثل GitHub Pages أو `python -m http.server`). لا تستخدم `file://` لأن `fetch` وService Worker يحتاجان origin.

## الملفات

- `index.html`: التطبيق الرئيسي.
- `admin.html`: لوحة إدارة محلية للمسودات.
- `data/content.json`: بيانات المحتوى التجريبية مع المصدر والحالة.
- `script.js`: منطق التطبيق وتخزين التفضيلات محليًا.
- `style.css`: الأنماط المشتركة.
- `sw.js`: التخزين المؤقت للـ PWA.

## حدود واضحة

لا يوجد Backend أو مصادقة أو قاعدة بيانات أو AI في هذه النسخة. لا يتم الادعاء بأن زر الصوت يشغل ملفات غير موجودة؛ طبقة الصوت تعرض حالة عدم توفر المصدر. لإضافة هذه الخدمات يلزم خادم ومصدر مرخص ومفاتيح سرية محفوظة في بيئة الخادم.
